Cozy Tidy Finds Operations Manual

Everything you need to run the site, post products, manage social media, and stay on the right side of Amazon's rules. If something isn't covered here, ask Jon.

1. Welcome & Quick Start

This is your guide to running Cozy Tidy Finds. Everything you need is here. You've got this.

Important Links

  • Live website: https://cozytidyfinds.com
  • GitHub repository (where the site files live): https://github.com/jonjenkins89-omega/cozytidyfinds.com

How to Edit the Site

  1. Go to the GitHub repository (link above)
  2. Navigate to the file you want to edit (for example, kitchen/index.html)
  3. Click the pencil icon in the top-right corner of the file to open the editor
  4. Make your changes right there in the browser
  5. Scroll down, type a short note about what you changed (like "Added bamboo organizer to kitchen"), and click Commit changes

How Changes Go Live

When you save (commit) to the main branch, GitHub automatically publishes your changes to the live site. It usually takes 1-2 minutes for the changes to show up. Just refresh the page after a couple minutes and you'll see them.

For bigger changes (adding new pages, changing the layout, anything that feels complicated), ask Jon for help. No need to struggle through it alone.

2. Adding a New Product

This is the thing you'll do the most. Here's how to add a product to any category page, step by step.

Step 1: Pick the Right Category Page

Decide which room/category the product belongs to, then open the matching file:

  • Kitchen → kitchen/index.html
  • Bathroom → bathroom/index.html
  • Organization → organization/index.html
  • Bedroom → bedroom/index.html
  • Plants → plants/index.html

Step 2: Find the Product Grid

Once you open the file, search for picks-grid (use Ctrl+F in the editor). That's the section where all the product cards live. You'll paste your new product inside this area.

Step 3: Copy This Template

Copy the code below and paste it inside the picks-grid section, right before the closing </div> that ends the grid (or after the last existing product card):

<div class="product-card">
    <div class="product-img">
        <div class="placeholder-card">Product Photo</div>
        <span class="badge badge-new">New Find</span>
    </div>
    <div class="product-info">
        <span class="category-tag">CATEGORY NAME</span>
        <h3>Product Name Here</h3>
        <div class="desc">Write 2-3 sentences about why you love
this product. Be honest and specific.</div>
        <div class="rating">&#9733;&#9733;&#9733;&#9733;&#9733;
X.X (X,XXX reviews)</div>
        <div class="price-row">
            <a href="https://www.amazon.com/dp/YOUR_ASIN_HERE?tag=cozytidyfinds-20"
               class="btn-shop affiliate-link"
               data-product="product-name-slug"
               data-category="category-name"
               target="_blank"
               rel="noopener nofollow sponsored">
               Check Price on Amazon
            </a>
        </div>
    </div>
</div>

Step 4: Find the ASIN on Amazon

Go to the product's page on Amazon and look at the URL in your browser's address bar. The ASIN is the 10-character code after /dp/. For example, in this URL:

https://www.amazon.com/dp/B08N5WRWNW/ref=...

The ASIN is B08N5WRWNW. Replace YOUR_ASIN_HERE in the template with this code.

Step 5: Fill In the Details

  1. Badge: Change badge-new to one of these:
    • badge-new → shows "New Find" (green)
    • badge-favorite → shows "Staff Pick" or "Best Value" (pink)
    • badge-trending → shows "Trending" or "Viral" (coral)
    Also change the text inside the <span> to match (e.g., "Staff Pick", "Trending", etc.)
  2. Category tag: Replace CATEGORY NAME with the room name in all caps (KITCHEN, BATHROOM, etc.)
  3. Product name: Replace Product Name Here with the actual product name
  4. Description: Write 2-3 sentences about why you like it. Keep it honest and real.
  5. Rating: Replace X.X with the star rating from Amazon (like 4.7) and X,XXX with the review count (like 2,847)
  6. data-product: Replace product-name-slug with a short, lowercase, hyphenated name (like bamboo-drawer-organizer). No spaces, no special characters.
  7. data-category: Replace category-name with the room name in lowercase (kitchen, bathroom, etc.)

Step 6: Save and Commit

Click Commit changes with a short description of what you added. Done! The product will show up on the live site within 1-2 minutes.

3. Updating the Navigation & Footer

The navigation bar at the top and the footer at the bottom appear on every single page of the site. They're marked in the code with special comments so you can find them:

  • Navigation: look for <!-- SHARED:NAV -->
  • Footer: look for <!-- SHARED:FOOTER -->
Important: If you change the nav or footer, you need to make the exact same change in ALL of these files. If you miss one, that page will have an outdated menu.

Files That Share the Nav & Footer

  • index.html (home page)
  • kitchen/index.html
  • bathroom/index.html
  • organization/index.html
  • bedroom/index.html
  • plants/index.html
  • about/index.html
  • blog/index.html
  • blog/best-kitchen-organizers-2026/index.html
  • Any future blog posts you create

The links page (links/index.html) has its own simpler layout and does NOT share the nav/footer. You can skip it when updating these.

Tip: Edit one file first to get it right. Then copy the entire nav block (from <!-- SHARED:NAV --> to <!-- /SHARED:NAV -->) and paste it into all the other files, replacing the old version. Same process for the footer.

4. Adding a Blog Post

Blog posts help with search engine traffic and give you something to link to from social media and emails. Here's how to create one:

Step 1: Create a New Folder

Under the blog/ folder, create a new folder with a URL-friendly name. Use lowercase letters, hyphens instead of spaces, no special characters. For example:

  • blog/best-bathroom-organizers-2026/
  • blog/spring-cleaning-checklist/
  • blog/5-minute-kitchen-declutter/

Step 2: Create index.html

Create an index.html file inside your new folder. The easiest approach: copy an existing blog post (like blog/best-kitchen-organizers-2026/index.html) and use it as your starting template.

Step 3: Update the Content

In your copied file, change these things:

  1. The <title> tag (the browser tab title)
  2. The meta description (the summary that shows in Google results)
  3. The canonical URL (should point to your new blog post's URL)
  4. The structured data (the JSON block at the top, update the title, description, and URL)
  5. The breadcrumb text
  6. The actual article content (the heading, paragraphs, product recommendations, etc.)

Step 4: Add a Card to the Blog Index

Open blog/index.html and add a card for your new post. Copy an existing blog card and update the title, description, link, and date.

Step 5: Update the Sitemap

Open sitemap.xml in the root folder and add your new blog post URL. Copy an existing entry and change the URL and date.

Step 6: Commit Everything

Save all the files you changed. Write a commit message like "Add spring cleaning blog post" and commit.

5. Email & Newsletter

We use Kit (formerly ConvertKit) for email signups and newsletters: https://app.kit.com

How It Works

The signup forms on the website post directly to Kit's servers. When someone subscribes, Kit handles the confirmation email and adds them to your subscriber list automatically. You don't need to do anything on the website side for this.

Never put Amazon affiliate links directly in emails. This violates Amazon's Terms of Service and can get the account terminated. Instead, link to blog posts or category pages on the website. Those pages already contain the affiliate links, and that's allowed.

Weekly "Friday Finds" Newsletter

  1. Pick 3-5 products you're excited about
  2. Write a short, personal note about each one (2-3 sentences)
  3. Link to the blog post or category page where the product lives (NOT directly to Amazon)
  4. Schedule the send for Friday morning

What Kit Can Do for You

  • Automated welcome emails for new subscribers
  • Scheduled newsletter sends
  • Subscriber management (see who's on your list, remove people, etc.)
  • Basic analytics (open rates, click rates)

6. Analytics & Tracking

Google Analytics

Visit https://analytics.google.com to see your site traffic.

Key things to check each week:

  • Total visitors: How many people visited the site?
  • Top pages: Which pages are people looking at the most?
  • Traffic sources: Where are visitors coming from? (Pinterest, Google, Instagram, etc.)
  • Affiliate clicks: The site tracks "affiliate_click" events. These tell you which products people are clicking on.

Amazon Associates Dashboard

Visit https://affiliate-program.amazon.com to see your earnings.

What you'll find there:

  • Clicks: How many people clicked through to Amazon from your links
  • Orders: How many of those people actually bought something
  • Earnings: How much commission you've earned

Check this daily during the first few months to see what's working and what's not. Amazon pays commissions 60 days after the month they're earned (so January earnings arrive in early April).

Your Weekly 5-Minute Check

Once a week, spend 5 minutes answering these questions:

  1. How many visitors came to the site this week?
  2. Which pages are the most popular?
  3. Which products are getting the most clicks?
  4. Did any orders come through?

That's it. Don't overthink it. Look for patterns over time, not day-to-day swings.

7. Social Media Cheat Sheet

Pinterest (Most Important, 40% of Your Effort)

Pinterest is your number one traffic driver. People search Pinterest like they search Google, and home/organization is Pinterest's single biggest category. This is your sweet spot.

  • Post 10-15 pins per day (3-5 original pins you create, the rest can be repins of related content)
  • Use keyword-rich titles and descriptions. Think about what someone would type to find your product (e.g., "small kitchen drawer organizer bamboo" not just "cute organizer")
  • Pins drive traffic for months, not just days like Instagram. A good pin can send traffic for a year or more.
  • Use Tailwind for scheduling so you're not pinning all day

Instagram (30% of Your Effort)

  • Reels: 4-7 per week. Reels are how new people find you.
  • Stories: Post daily. Use link stickers to send people directly to products.
  • Carousels: 2-3 per week. Great for "before and after" or "top 5" style posts.
  • Best posting times: Tuesday, Wednesday, Thursday at 6-9 AM, 12-1 PM, or 7-9 PM

TikTok (20% of Your Effort)

  • Post 2-3 videos per day
  • Before/after transformation videos perform the best (messy drawer → organized drawer, cluttered counter → clean counter)
  • Use the "Comment LINK" strategy: tell people to comment "LINK" and then send them the product link via DM
  • Best posting times: Tuesday, Thursday, Friday at 7-9 AM, 12-3 PM, or 7-11 PM

Remaining 10%: Engage & Respond

Spend the remaining time replying to comments, answering DMs, and engaging with other accounts in the home/organization space.

Updating the Link-in-Bio Page

Your social media bios link to the Link-in-Bio page. To add, remove, or reorder links, edit links/index.html. This is the one-stop page people land on from your Instagram, TikTok, and Pinterest bios.

Disclosure on Social Posts

Always include a disclosure on social posts with affiliate links. The FTC requires this. Add one of these hashtags to every post that includes or leads to an affiliate link: #ad, #affiliate, or #AmazonAssociate. Put it where people can actually see it (not buried under 30 other hashtags).

8. Rules That Cannot Be Broken

These are compliance rules from Amazon, the FTC, and common sense. Breaking them can get the affiliate account shut down, get fined, or both. Read this section carefully and follow it without exception.
  1. Never show product prices on the website. Amazon changes prices constantly (sometimes multiple times per day). Showing a price that doesn't match Amazon's current price violates their Terms of Service. That's why every product uses the "Check Price on Amazon" button instead of listing a price.
  2. Never put affiliate links in emails. Amazon's Terms of Service explicitly prohibit this. Always link to a blog post or category page on the website instead. The page contains the affiliate link, and that's the allowed approach.
  3. Never offer rewards for clicking affiliate links. No "click my link and I'll send you a freebie" deals. No contests that require clicking affiliate links. No incentives of any kind.
  4. Always include affiliate disclosure. On the website, the disclosure bar at the top of every page handles this automatically. On social media, use #ad or #affiliate or #AmazonAssociate on any post with affiliate links.
  5. Never buy products through your own affiliate links. Amazon tracks this and will terminate the account. Not "might." Will.
  6. Make 3 qualifying sales within 180 days. After the Amazon Associates account is approved, you need 3 real sales within 180 days or the account gets closed. You can reapply, but it's better to just hit those 3 sales early. Focus on this first.
  7. Never use Amazon's product images without permission. Amazon's own product photos are copyrighted. Take your own photos of products, or use the placeholder cards already on the site until you have your own photos.
  8. Never bid on Amazon trademarks in paid ads. If you ever run Google Ads or Facebook Ads, do not use "Amazon," "Kindle," "Prime," or any other Amazon trademark as a keyword. Amazon will terminate your affiliate account for this.

9. Content Calendar & Seasonal Planning

Home and organization content is seasonal. The products people want in January (New Year's declutter motivation) are completely different from July (summer outdoor living). Plan your content around these themes:

Monthly Themes

  • January: New Year organization, declutter challenge, "fresh start" content
  • February: Valentine's Day gifts, cozy winter products, small space organization
  • March-April: Spring cleaning, garage/closet organization, refresh your space
  • May: Mother's Day gift guide (huge traffic opportunity)
  • June: Summer organizing, outdoor living, patio and garden
  • July: Amazon Prime Day (prepare content 6-8 weeks early!)
  • August: Back-to-school, dorm room organization, getting ready for fall
  • September-October: Fall cozy season, Halloween decor, holiday prep starts
  • November: Black Friday / Cyber Monday (this is the biggest revenue month of the year)
  • December: Holiday gift guides, New Year prep, stocking stuffers
Key rule: Publish seasonal content 6-8 weeks BEFORE the event so it has time to rank in search engines and get picked up by Pinterest. A "Black Friday Gift Guide" published on November 25th is too late. Publish it in early October.

10. Product Card Template (Ready to Copy)

Here's the product card template again, all in one place. Copy this whenever you need to add a product. The field reference below explains what each piece does.

<div class="product-card">
    <div class="product-img">
        <div class="placeholder-card">Product Photo</div>
        <span class="badge badge-new">New Find</span>
    </div>
    <div class="product-info">
        <span class="category-tag">CATEGORY NAME</span>
        <h3>Product Name Here</h3>
        <div class="desc">Write 2-3 sentences about why you love
this product. Be honest and specific.</div>
        <div class="rating">&#9733;&#9733;&#9733;&#9733;&#9733;
X.X (X,XXX reviews)</div>
        <div class="price-row">
            <a href="https://www.amazon.com/dp/YOUR_ASIN_HERE?tag=cozytidyfinds-20"
               class="btn-shop affiliate-link"
               data-product="product-name-slug"
               data-category="category-name"
               target="_blank"
               rel="noopener nofollow sponsored">
               Check Price on Amazon
            </a>
        </div>
    </div>
</div>

Field Reference

  • badge-new / badge-favorite / badge-trending — Controls the colored label on the product image. Pick the one that fits.
  • CATEGORY NAME — The room name in all caps: KITCHEN, BATHROOM, ORGANIZATION, BEDROOM, or PLANTS.
  • Product Name Here — The product's name. Keep it readable (you don't need the full Amazon listing title with all the keywords).
  • desc — Your personal take on the product. 2-3 sentences. Why do you like it? What makes it worth buying?
  • rating — The star rating and review count from Amazon. The &#9733; codes display star symbols.
  • YOUR_ASIN_HERE — The 10-character product code from the Amazon URL (after /dp/).
  • tag=cozytidyfinds-20 — This is the affiliate tracking tag. Never change this. It's how Amazon knows the click came from us.
  • data-product — A short slug for analytics tracking (like bamboo-drawer-organizer). Lowercase, hyphens, no spaces.
  • data-category — The room name in lowercase for tracking: kitchen, bathroom, organization, bedroom, or plants.

That's everything! If you get stuck on anything, ask Jon. He built this thing and can help you with whatever comes up.
